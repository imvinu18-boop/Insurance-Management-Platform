🛡️ InsurShield - Comprehensive Insurance Management Portal
InsurShield is a modern, role-based Web Application built for managing insurance policies, customer requests, premium payments, and claims processing seamlessly. The platform provides tailored dashboards and workflows for Customers, Agents, and Admins.

✨ Key Features
🔐 Role-Based Authentication & Access Control:

Secure login and registration supporting multiple roles: Customer, Agent, and Admin.

Dynamic navigation and route protection based on user roles.

📄 Policy Management:

Customers: Browse available insurance plans (Health, Life, Vehicle, Travel), apply for new policies, and track application statuses.

Agents & Admins: Register policies directly, review incoming customer requests, assign nominees, and manage active customer portfolios.

💳 Payments & Billing:

Track premium payment statuses, frequencies (Monthly, Quarterly, Yearly, One-Time), and transaction histories.

📋 Claims Processing:

Submit, track, and manage insurance claims efficiently within the portal.

👥 Customers Directory & Reports:

Agents and Admins can view comprehensive customer directories and analytical reports.

🛠️ Tech Stack
Frontend: React.js, React Router DOM

Styling: Tailwind CSS (for responsive and modern UI design)

State Management & Storage: React Context API, LocalStorage (for persistent client-side mock backend)
